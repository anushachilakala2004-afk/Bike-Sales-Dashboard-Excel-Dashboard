# 🚲 Bike Sales Analysis Dashboard – Excel

## 📌 Project Overview

This project analyzes customer data to understand **bike purchasing behavior** using Microsoft Excel.

The project covers customer demographics, income, education, occupation, region, commute distance, age group, and bike purchase status.

An interactive **Bike Sales Analysis Dashboard** was created using PivotTables, PivotCharts, KPI cards, and Slicers.

---

## 🎯 Project Objectives

- Analyze customer demographics
- Understand bike purchasing behavior
- Compare bike purchases by gender and age group
- Analyze purchases across regions
- Study commute distance and occupation patterns
- Analyze income in relation to bike purchases
- Build an interactive Excel dashboard
